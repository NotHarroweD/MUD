# Prototype plan

## Testable vertical slice

One player completes a Cinderwood Hunt against the Ashmaw. The canvas portrays the encounter; the DOM shell provides health, intent, actions, log, loot reveal, inventory, equipment comparison, milestone, and an explicit rare-loot test toggle.

## Acceptance path

1. Start the hunt.
2. Read the Ashmaw intent.
3. Strike or Brace before the telegraphed burst.
4. Win or lose with a clear resolution.
5. Receive gold, experience, and a revealed item.
6. Inspect an item and equip an upgrade.
7. Purchase a level-two trait and see the next goal.
8. Enable guaranteed rare loot and repeat to inspect the rare item.

## Out of scope

Persistent saves, account creation, a production economy, trading, chat, multiplayer synchronization, procedural content, and real-time movement.
